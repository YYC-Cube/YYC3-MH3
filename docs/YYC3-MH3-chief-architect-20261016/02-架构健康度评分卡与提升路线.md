## 〇、评分方法（杜绝"感觉良好"）

**唯一口径**：一条指标若不能给出「可复现命令 + 采集到的原始数值」，一律标记 ❌ 不可测并计 **0 分**，禁止用形容词（"流畅""稳定""良好"）替代。

| 状态 | 定义 | 计分 |
| --- | --- | --- |
| ✅ 实测达标 | 有命令、有原始数值、落入门禁 | 满分 |
| 🟠 实测但有缺口 | 有数值但未覆盖全部范围（如契约端口有遗漏） | 部分分 |
| ⚠️ 部分可测 | 采集能力存在但不完整（如结构化日志缺字段） | 低分 |
| ❌ 不可测 | **无任何采集能力**（无代码/无工具/无命令） | **0** |

> 本仓实测基线（第七批后）：`tsc --noEmit` ✅ 0 error ｜ `vitest run` ✅ 32 文件 / 288 用例全绿 ｜ 覆盖率 语句 88.44% / 函数 86.02% / 分支 83.18% / 行 90.85%（阈值 80/80/80/75；稀释原因为 registry-server.ts 0% 单测进分母，详见 §十三 13.4）｜ `check:size` ✅ JS 1076.4KB · 最大 chunk 229.5KB · CSS 87.7KB ｜ `pnpm audit --prod` ✅ 0 高危 ｜ `check:lint` ✅ 0 error ｜ `check:csp` ✅ 16 页哈希化 ｜ `check:lighthouse` ✅ perf 0.73 / bp 1.0（csp-xss=1）｜ `check:obs` ✅ 六步链全通。
