## 关键决策记录

| 决策 | 背景 | 选择 | 原因 |
| --- | --- | --- | --- |
| dev 装配由 local BFF 切至 auto-IDB | P4-2 组合根演进 | dev/生产统一 `createPorts("auto")`：浏览器且有 IDB → IDB 持久化仓库；SSR/测试/旧浏览器 → memory 自动回退 | 数据主权必须真实可拥有；memory 回退保证 SSR 首屏与测试零改动 |
| local 适配器保留未接线 | Registry BFF 契约已定义（06 §2）但后端未落地 | `adapters/local` 代码保留、不接入组合根 | 契约先行不删通道；待 BFF 落地后按端口即插即用 |
| `data/` 保留 4 个展示目录文件 | P1-2 夹具化裁定 | `agent/content/design/yyc3Data.ts` 保留原位（仅设计系统展示目录静态数据），生产域夹具已迁 `adapters/memory/fixtures/` | 展示数据与生产数据通道语义分离，避免过度迁移 |
| 数据主权通道经 types 承载契约 | views 禁触 app 层（boundary 红线） | ExportEnvelope / ImportResult 定义在 `types/platform.ts`，usecases 与视图双向引用契约；通道实例经 `settings/page.tsx` props 注入 | 分层零越界前提下实现 app ↔ views 装配 |
| SettingsView 保存配置 toast 措辞保留 | P4-3 文案真实化裁定 | 该按钮无真实持久化语义 → 保留「刷新即重置」原措辞 | 诚实优先：不虚报能力 |
| SSE 全链路以 Node 侧等价验证替代浏览器联调 | Track B（静态导出）与 API Route 互斥，浏览器层 SSE 须待 Track A | `sse.integration.test.ts`：node:http 薄壳 + fetch 流分帧 EventSource 替身，真 TCP socket + 真实 SSE 分帧 | 线协议逐字节等价于浏览器 EventSource 消费形态；比 mock 高信度，且不阻塞于 Track A |
| 冒烟伺服自带 .html 回退 | python http.server 不映射 /settings → settings.html（Next 静态导出无目录 index） | `HtmlFallbackHandler.translate_path`：目录→index.html、无后缀→.html | 零新增依赖（纯标准库），脚本自管伺服线程 |
